# task26092941-b

进程内采集调度库（Go，仅内存状态）。上层传入采集回调，调度器负责并行度控制、
错误窗口统计、自动降级、退避重试与取消。

## 能力

- `sched.New()` 创建调度器；`Submit(source, cb)` 提交任务，回调返回 `bool` 表示成功/失败。
- `Task.Cancel()` 取消（已终结则无效）；`Task.Wait()` 阻塞等待终态；`Task.State()` 查询状态。
- 全局最多 8 路并行；同一数据源正常最多 4 路，降级最多 1 路。
  名额自获准执行起占用，直到回调返回才释放。
- 每个源独立统计最近 300 秒完成的尝试，失败占比严格大于 15% 时降级；
  样本过期由定时器触发重新判断，无需等待新的完成。
- 失败后按 60/120/240/480 秒退避重试，最多执行 5 次；等待重试不占执行名额。
- 取消不中断已获准的回调，但其结果被丢弃：不进错误窗口、不覆盖取消终态。

## 测试

```sh
go test ./...
# 竞态检测（沙箱内需可写的 GOCACHE）
CGO_ENABLED=1 GOCACHE=/private/tmp/gocache-race go test -race ./...
```

窗口阈值、过期恢复、降级取消、重试退避、全局名额与准入顺序。
